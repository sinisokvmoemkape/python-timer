# Python-Timer

Простой консольный будильник на Python с использованием 
библиотек time, datetime и playsound3. 

Проект будет развиваться и масштабироваться по мере 
моего обучения до уровня качественного Back-end кода.

## Инструкция по запуску

### Linux / macOS
```bash
chmod +x linux_macos_run.fish
./linux_macos_run.fish
```

### Windows (Не протестировано)
```cmd
windows_run.bat
```

## Смена мелодии

Чтобы изменить звуковой сигнал, переместите любой 
аудиофайл формата MP3 или WAV в корневую папку 
проекта и переименуйте его в `melody` 
(например, `melody.mp3`).
